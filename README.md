📑 FinancialAccounting
---
FinancialAccounting — это легкое и функциональное SPA-приложение для управления личными финансами.
Проект построен на принципах Clean Architecture и ориентирован на детальную аналитику и удобное управление накоплениями без использования тяжелых фронтенд-фреймворков

🚀 Основные возможности
---
- Мультивалютные счета: Создание и управление неограниченным количеством кошельков.

- Умная аналитика: Динамический дашборд с распределением средств по счетам и фильтрацией доходов/расходов по категориям, месяцам и годам 

- Система целей (Копилки): 

- Привязанные цели: мониторинг прогресса накопления прямо на балансе счета 

- Автономные цели: независимые копилки с собственной историей транзакций 

- Чистая статистика: Логика системы исключает внутренние переводы между счетами из общей аналитики доходов и расходов, обеспечивая "честные" цифры бюджета 

- Интерактивный UI: Создание категорий в форме транзакции и мгновенная фильтрация данных кликом по карточкам статистики 

🛠 Технологический стек
---
Backend:
- .NET 10 / ASP.NET Core Web API
- Clean Architecture: четкое разделение на слои (Entities, Presenters, Application, Infrastructure)
- Entity Framework Core: взаимодействие с БД и миграции
- MS SQL Server: хранение данных

Frontend:
- Vanilla JavaScript: SPA-архитектура без сторонних библиотек
- CSS3: современная верстка с использованием Flexbox и Grid
- Fetch API: асинхронное взаимодействие с бэкендом


🏗 Интересные архитектурные решения
---
- Мягкое удаление: реализовано безопасное удаление категорий, что сохраняет целостность истории транзакций
- Невозможность удалить ранние транзакци: деньги не уходят в никуда и не приходят из ниоткуда
- Использование DTO: использование рекордов для передачи данных, минимизирующее накладные расходы и упрощающее поддержку кода

🛠 Установка и запуск
---
Требования:
- .NET 10 SDK
- MS SQL Server (LocalDB)

Запуск
---
1. Склонируйте репозиторий
2. Обновите строку подключения в appsettings.json
3. Примените миграции: dotnet ef database update
4. Запустите проект: dotnet run
5. Откройте index.html в любом современном браузере
